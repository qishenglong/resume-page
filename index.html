标志性工作经历（重点项目精选）

中信保诚外围批处理 C2J 架构重构项目

项目经理 | 2024.11

背景与目标： 针对保险 AS400 平台 COBOL 遗留系统信创不足、扩展弱的痛点，主导批处理系统现代化重构（过程式 COBOL 到 SpringBoot Java 架构）。

核心技术动作：
1. 设计数据结构、语法、运行语义全套映射规则；落地自动化迁移工具链，实现 CPY / 程序文件批量转 Java 实体。
2. 针对分布式 IO 瓶颈实施批量提交、合并查询、内存缓存优化。
3. 搭建双轨并行全量数据核对 + JACOCO 覆盖率分析的闭环质量体系。

成果与价值： 性能大幅提升，保障业务逻辑无损，支撑系统平滑信创上线，彻底解决原主机系统人才短缺的技术债务。

国寿海外团险同构亿级数据迁移项目

项目经理 | 2023.09

核心挑战： 将系统数据库从 SQL Server 迁至 MySQL，涉及整库亿级、最大单表千万级数据，迁移窗口要求极高。

技术攻坚： 制定多数据源连接、多线程批量提交及全量比对策略；攻克外键约束、MySQL 关键字冲突、无主键大表、时区兼容、LONGTEXT 类型转换等多项难点。

落地结果： 实现 4 小时内 完成全量清洗、迁移与行级比对，生产环境核对通过率 100%。系统平稳上线，显著降低了运维成本。

PICC 人保健康商保核心架构升级（信创）

系统架构设计师 | 2022.04

架构设计方案： 全面建成了用户、产品、客户、收付费及团险专属中心。采用基于 Spring Boot + Consul 的微服务体系，结合 Apollo 配置中心、Zuul API 网关。

高可用与信创： 采用分布式数据库 GaussDB 与 PGSQL 并存；部署 DNS + LVS + KeepAlived 实现高可用负载均衡；引入 Kafka / RocketMQ 实现事务解耦。

可观测性建设： 使用 ELK + SkyWalking 搭建完整的分布式日志追踪与全链路监控系统，结合 Prometheus 构建云原生可观测能力，支持灰度发布与两地三中心异地双活。
